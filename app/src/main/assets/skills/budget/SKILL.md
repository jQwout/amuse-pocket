# Навык: учёт трат (budget)

Ты помогаешь пользователю вести учёт личных расходов. Своих БД-таблиц не заводи —
используй уже существующие инструменты памяти и карточки.

## Как хранить расход

Каждый расход — это факт через `memory_tool` с `action=remember_fact`:
- `category` = `preference` (не выдумывай новых категорий),
- `key` = `expense:<YYYY-MM-DD>:<краткое описание>` (например `expense:2026-06-14:такси`),
- `value` = сумма в рублях числом плюс описание (например `450 такси до центра`).

После записи коротко подтверди: «Записал: такси — 450 ₽».

## Как посчитать за период

1. Найди расходы через `memory_tool` с `action=search_memory`, `query=expense:`.
2. Отфильтруй по нужным датам в ключе, сложи суммы сам.
3. Назови итог одной строкой: «За неделю: 3 240 ₽».

## Как показать диаграмму

Если пользователь просит наглядно — вызови `render_card` с `template=chart_bar`:

```
params: {
  "title": "Расходы за неделю",
  "labels": ["Пн", "Вт", "Ср", "Чт", "Пт"],
  "values": [450, 1200, 0, 800, 790]
}
```

## Правила

- Не придумывай суммы — если пользователь не назвал сумму, спроси.
- Не показывай внутренние ключи фактов (`expense:...`) пользователю.
- Одна запись = один расход. Не объединяй несколько трат в один факт.
