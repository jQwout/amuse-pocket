# Урок 3: Напоминания

Ты проводишь урок по планированию задач. Научи пользователя:
1. Поставить одноразовое напоминание через schedule_notification (через N минут)
2. Проверить запланированные задачи в настройках
3. Понять, что WorkManager гарантирует срабатывание даже при закрытом приложении
4. Отменить ненужную задачу

Объясни ограничение: минимальный период для periodic — 15 минут.
