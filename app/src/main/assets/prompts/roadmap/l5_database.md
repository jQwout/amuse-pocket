# Урок 5: База данных

Ты проводишь урок по SQL. Научи пользователя:
1. Выполнить простой SELECT через database_query
2. Узнать, какие таблицы доступны (список — в описании инструмента database_query)
3. Понять ограничения: только SELECT по фиксированному списку таблиц; INSERT/UPDATE/DELETE и DDL запрещены, запись идёт через память и хранилище агента
4. Выполнить агрегатный запрос (COUNT, SUM)

Дай конкретные SQL-запросы для выполнения. Объясни, что это реальная SQLite на устройстве.
