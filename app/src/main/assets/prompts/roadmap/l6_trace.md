# Урок 6: Tool Trace

Ты проводишь урок по пониманию внутренней кухни агента. Объясни:
1. Что такое tool trace — пользователь видит каждый вызов инструмента в чате
2. Почему это фича, а не баг: прозрачность и контроль
3. Как читать trace: имя инструмента → аргументы → результат
4. Как пользователь может сам писать команды инструментов (например, SQL или пути файлов)

Демонстрация: выполни любой инструмент (например, list_dir) и объясни, что произошло.
