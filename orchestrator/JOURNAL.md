Непроверенное называется непроверенным: цифры под цель не подгоняются.

## Решения владельца

- **27.10.2026, перенос оркестратора.** Владелец запустил перенос из `xrchief` по его
  `orchestrator/PORTING.md` и ответил на вопросы раздела 1:
  - **Цель и срок:** «Сдача на Meta-хакатон, 4 ноя». Критерии — требования хакатона (R), техника (T),
    продукт/демо-путь (P), предложения (Q).
  - **Границы:** «Пушить рабочие ветки можно» — коммиты, ветки `orch/*`, слияние в рабочую ветку и push
    этих веток в origin без спроса; `main`, публикации, деньги, ключи, установка программ — только по
    явному «да» в чате.
  - **Рабочая ветка:** «mvp».
  - **Устройство:** «Эмулятор свободно, Pixel — по „да“». Телефон владельца — боевое приложение,
    установка поверх может стереть базу.
- **27.10.2026, бюджет.** Записан как $0 по умолчанию (владелец не называл сумму): ключ из `.env` — его
  квота, платные вызовы из кода оркестратора и скриптов не делаются. Если это не так — поправить
  `AUTONOMY.md`, менять его может только владелец.

- **Рабочая ветка `mvp` сдвинута вперёд.** На момент переноса `mvp` стоял на `71a431b` (11 июля), а вся
  работа по хакатону лежала на `claude/visible-branches-m4vb7j` — 276 коммитов впереди. `mvp` оказался
  строгим предком этой ветки (`git rev-list --left-right --count mvp...HEAD` → `0 276`), поэтому
  сделан fast-forward: `mvp` теперь на `657c1e2`. Ничего не потеряно, откат — `git branch -f mvp 71a431b`.
  Владельцу сказано отдельно: он выбирал `mvp`, считая её актуальной.

- **`tools/check.py` — одна команда проверки.** Десять проверок, ID совпадают с `CRITERIA.md`:
  R2 (прямой маршрут Meta), R3 (коммиты в окне), R7 (английские сообщения коммитов), T1 (сборка),
  T2 (весь набор тестов), T3 (`traxer check`), T4 (ключи и артефакты в git, сторож релиза),
  T4a (ключи внутри APK), T6 (английская сторона `tr()`), T6b (английские уроки демо-пути).
  Исходник — только ASCII (кириллица через `\uXXXX`): на этой машине консоль в cp1251, и служебный
  скрипт с кириллицей уже падал в парсере не на той строке.
