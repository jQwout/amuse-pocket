# Критерии готовности AI Open Pocket

Единственный вход владельца в работу оркестратора. Цель — все критерии групп R, T и P в ✅ к сдаче на
Meta Global AI Developer Hackathon: **4 ноября 2026, 21:00 ET** (5 ноя, 03:00 по Белграду).

**Статусы:**
- ✅ — подтверждено проверкой;
- ❌ — не выполнено;
- ⚠️ — есть замечания;
- ❔ — не проверено (обычно нужен прогон на эмуляторе);
- ☐ — ещё не начато.

Статус меняется только по доказательству: вывод `tools/check.py`, отчёт `device-tester`, решение
владельца. Что не проверено на устройстве — остаётся ❔, даже если код выглядит правильным.

**Как проверяется:**
- `auto` — `python tools/check.py` (ID в выводе — это ID отсюда);
- `device` — агент `device-tester` на эмуляторе;
- `review` — агент `verifier` по коду;
- `owner` — только владелец.

Менять формулировки, добавлять и удалять критерии может только владелец. Оркестратор предлагает правку
в отчёте по вехе.
