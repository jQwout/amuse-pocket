# Глассморфизм-редизайн + карточка агента (инспектор): Home, Чат, Тулы, Онбординг

**Дата:** 2026-07-04
**Ветка реализации:** `feature/glassmorphism` (создать от текущей рабочей ветки `mvp`)
**Статус:** дизайн утверждён, ждёт плана реализации

## Цель

Перевести четыре зоны UI — Home, Чат, Тулы (AgentsScreen), Онбординг — на единый
глассморфизм-стиль: полупрозрачные «стеклянные» поверхности с размытием подложки,
градиентные блики на гранях, аурора-фон. **Меняем только стиль**: структура экранов,
тексты, навигация и контент остаются как есть. Типографика (Lora для заголовков)
не трогается.

Плюс один **новый экран** — карточка агента (read-mostly инспектор), который строится
сразу в стеклянном стиле (см. раздел 2).

## Принятые решения

| Вопрос | Решение |
|---|---|
| Глубина | Полный редизайн: общая glass-дизайн-система + все экраны на неё |
| Техника стекла | Библиотека Haze: настоящий backdrop-blur на API 31+, автофолбэк (tint без blur) на API 24–30 |
| Фон | Статичная «аурора»: тёмная база + 2–3 радиальных градиентных пятна, без анимации |
| Чат | Настоящий blur только на неподвижной обвязке; пузыри и driven-ui карточки — имитация без blur |
| Экран Тулы | Скриншот-референс — только настроение; контент остаётся текущим (список агентов) |
| Онбординг | Включён в скоуп, тоже только стиль |
| Карточка агента | Новый экран, read-mostly инспектор в стекле; открывается тапом по агенту на «Тулах» |
| Охват карточки | 6 реальных мини-агентов из `MiniAgentCatalog`; главного «AI Academy»-агента как сущности нет |
| Редактирование/хуки карточки | Вне скоупа: полный пульт (`agent_config`, редактирование, функциональные тумблеры) — отдельной фичей |

## 1. Дизайн-система стекла

Новая зависимость: `dev.chrisbanes.haze:haze` + `dev.chrisbanes.haze:haze-materials`.
Haze сам делает version-gating: на API 31+ рисует настоящий backdrop-blur через
RenderEffect, на API 24–30 — полупрозрачный tint-фолбэк. Наш код одинаковый для всех API.

Новые файлы:

- **`ui/theme/GlassTokens.kt`** — токены:
  - tint стеклянной поверхности: белый с alpha ~0.06–0.10 поверх тёмной подложки;
  - градиентный бордер 1dp: белый 25% → 5% сверху-вниз (блик на грани);
  - радиус blur ~20dp;
  - два тира: **strong glass** (навигация, топбары, инпут-бары — с настоящим blur)
    и **light glass** (карточки в скролл-контенте — имитация без blur);
  - цвета ауроры: производные от `PurpleAccent` + глубокий синий.
- **`ui/components/AuroraBackground.kt`** — фон всех экранов: `DarkBg` + 2–3 статичных
  радиальных градиентных пятна через `drawBehind` (без рекомпозиций). Этот слой —
  `hazeSource` для стеклянной обвязки экрана.
- **`ui/components/GlassSurface.kt`** — strong glass: обёртка с `hazeEffect`
  (настоящий blur того, что под поверхностью) + tint + градиентный бордер.
- **`ui/components/GlassCard.kt`** — light glass: имитация без blur
  (полупрозрачный tint + градиентный бордер + скруглённые углы). Безопасна внутри
  LazyColumn-item'ов.

Существующие шейпы сохраняются: 20dp основные карточки, 16dp сообщения, 28dp навигация.

## 2. Экраны

### Home (`ui/home/HomeScreen.kt`)
- Фон → `AuroraBackground`.
- `NewChatCard`, `AgentsEntryCard`, `RecentChatCard`, `CourseCard` → `GlassCard`.
- Hero-блок и Lora-заголовки — без изменений.

### Чат (`ui/chat/ChatScreen.kt`)
- Фон → `AuroraBackground`, лента сообщений — `hazeSource`.
- Настоящее стекло (`GlassSurface`) только на неподвижной обвязке: топбар,
  табы Чат/План/Цель, инпут-бар. Контент скроллится «под стеклом».
- Пузыри (`StreamingBubble`, user bubble) и все driven-ui карточки
  (`DrivenUiEngine.kt`) → `GlassCard`-имитация. **Blur внутрь item'ов LazyColumn
  не попадает** — это главный гардрейл, чтобы не вернуть лаги, починенные на
  `fix/chat-lag`.

### Тулы (`ui/agents/AgentsScreen.kt`)
- Фон → `AuroraBackground`.
- `AgentCard`, `CapabilityChip` → `GlassCard`.
- Топбар `AcademyCollapsingScaffold` → `GlassSurface` (blur заметен при коллапсе,
  когда контент подъезжает под бар).

### Нижняя навигация (`ui/components/AcademyBottomNav.kt`)
- Плавающая таблетка → `GlassSurface`: главный «вау»-элемент, контент экрана
  виден размытым сквозь неё. Текущая тень уменьшается/заменяется бликом-бордером.

### Онбординг (`ui/onboarding/`)
- Обвязка `OnboardingScreen`/`OnboardingContent`: топбар с прогрессом и нижняя
  панель «Назад / Далее» → `GlassSurface` (неподвижны, шаг скроллится под ними).
- `LanguageSelectionStep`: карточки RU/GB/DE → `GlassCard`; выбранная — усиленный
  фиолетовый бордер-блик; залоченные («Скоро») — приглушённый tint.
- `AboutMeStep`: поля анкеты → стеклянные инпуты (tint + градиентный бордер вместо
  плоского контура `OutlinedTextField`).
- `PersonaSelectionStep`/`PersonaCard`: перевод с `PersonaCardBg`/`PersonaQuoteBg`
  на glass-токены, `GlassCard`-имитация.
- `IntroStreamingStep`, `WrapupStep`: фон + существующие поверхности на glass-токены.
- Один `AuroraBackground`/`hazeSource` на весь флоу.

### Карточка агента — read-mostly инспектор (НОВЫЙ экран, не рестайл)

**Форма:** glass-модальный лист (bottom sheet) поверх «Тулов» — blur размывает
список агентов под ним. Drag-хэндл сверху + крестик. Открывается тапом по `AgentCard`.
Точка входа: сейчас тап по карточке сразу открывает чат — меняем на «тап → инспектор»,
а запуск чата делаем действием **«Открыть чат»** внутри инспектора.

**Охват:** 6 реальных мини-агентов (`MiniAgentCatalog`: budget / languages / tasks /
reminders / nutrition / diary). Главного «AI Academy»-агента как сущности в коде нет —
основной ассистент это персона, а не агент; в скоуп карточки не входит.

**Роль:** read-mostly инспектор. В этой итерации ничего не редактируется и не
переключается (редактирование и функциональные хуки — см. раздел 5).

**Вкладки:** Обзор / Файлы (glass-сегмент).

**Обзор** (всё read-only, реальные данные):
- Шапка: иконка `iconFor(iconKey)`, имя `agent.name`, под ним `agent.id` +
  эффективная модель (глобальный `selected_model` / AUTO).
- 4 стат-плитки (light glass) — **честные, вместо фейковых из макета**
  (Статус/Аптайм/Контекст для мини-агентов не существуют): **Модель**,
  **Temperature** (эффективная / «по умолчанию»), **Тулов: N** (`toolNames.size`),
  **Навык** (budget/diary/… либо «—»).
- **Препромпт**: `agent.systemPrompt`, read-only, скроллящийся стеклянный инсет.
- **Heartbeat**: из `HeartbeatDao.observe`/`listActive` по `agentId` — интервал,
  последний запуск, статус, чипсы задач; пустое состояние, если активных нет.
- **Возможности**: чипсы `capabilityLabels(agent.toolNames)`.
- **Хуки** (read-only, «на будущее»): `on_tool_call` показан активным (логирование/
  трейс реально существуют); `pre_message` / `post_message` / `on_error` — «скоро»,
  без тумблеров.

**Файлы:** содержимое общей песочницы `filesDir/agent` через `file_tool list_dir`
(имя, размер, изменён), read-only. Пометка, что папка **общая** для всех агентов
(per-agent workspace нет).

**Стекло:** весь лист — strong glass; плитки / инсет препромпта / строки — light glass.
Строится в стеклянном стиле сразу.

**Реальность кода (разведка, для плана):** per-agent конфига нет (ни Room, ни
DataStore); у `MiniAgent` нет модели/temperature; temperature — per-model в
`assets/config/models.json`; из 4 хуков живёт только `on_tool_call`; `on_error`
retry+backoff отсутствует (есть провайдер-фолбэк без backoff + ручная кнопка Retry);
эмбеддингов/векторной индексации нет; heartbeat-интервал показать легко, редактировать —
готового API нет.

## 3. Перфоманс-гардрейлы

1. Настоящий blur — только на неподвижной обвязке; **никогда** внутри item'ов
   LazyColumn.
2. Аурора статична, рисуется в `drawBehind` — ноль рекомпозиций.
3. Один `hazeSource` на экран.
4. На API 24–30 blur отсутствует (tint-фолбэк) — считается приемлемым видом,
   стиль сохраняется за счёт полупрозрачности и бордеров.

## 4. Проверка

- Сборка `assembleDebug` без ошибок.
- Визуальная проверка на устройстве API 31+ (настоящий blur) и, по возможности,
  на эмуляторе API 24–30 (фолбэк).
- Прогон стриминга в чате: скролл и печать ответа без лагов (регресс-чек к
  `fix/chat-lag`).
- Карточка агента: открытие по всем 6 агентам, корректные реальные данные,
  пустые состояния (нет heartbeat / нет файлов).
- `traxer check` / bless затронутых фич.

## 5. Вне скоупа

- Анимация ауроры (живой дрейф пятен).
- Изменение контента/структуры любого экрана (в т.ч. приведение Тулов к
  скриншоту-мокапу с метриками и интеграциями).
- Светлая тема.
- **Полный редактируемый «пульт управления» агентом**: новая Room-таблица
  `agent_config` (keyed by `agentId`), редактирование препромпта / temperature /
  интервала heartbeat, проводка в `PrePromptAssembler` / `ProviderConfig` /
  `HeartbeatDao`.
- **Функциональные тумблеры хуков** и 3 недостающих поведения: `pre_message`/PII-чистка,
  `on_error` retry+backoff, `post_message` семантическая индексация/эмбеддинги.
- **Per-agent рабочая папка файлов**; превью и редактирование файлов во вкладке «Файлы».
