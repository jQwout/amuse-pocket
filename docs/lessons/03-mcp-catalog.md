# Урок 03: какие MCP-серверы подключить и как

> **Цель урока.** После теории из [урока 02](./02-mcp.md) — собрать практический
> набор: какие конкретные MCP-серверы имеет смысл подключить к нашему
> ассистенту, какой навык приложения каждый из них «питает», и как именно их
> подключить тремя способами (Claude Code, Claude Desktop, наше приложение).
>
> **Связь с уроком 01.** Локальные навыки (`weather_card`, `todo_list`, `table`,
> `chart_bar`, `timer`) умеют красиво *рисовать* данные, но сами данные взять
> неоткуда — они приходят из фантазии модели. MCP-сервер даёт этим карточкам
> **реальный источник данных**. Связка простая: *внешний MCP-инструмент добывает
> данные → локальный навык их рисует*.

---

## 1. Три способа подключить любой MCP-сервер

Это эталонный раздел — дальше в каталоге мы будем на него ссылаться. Команды
проверены (Claude Code, июнь 2026).

### Способ A — Claude Code (CLI)

```bash
# Локальный сервер по stdio (запускается как процесс):
claude mcp add <имя> --transport stdio -- <команда> [аргументы...]

# Удалённый сервер по HTTP (по URL):
claude mcp add <имя> --transport http <url>

# С переменными окружения (ключи API):
claude mcp add <имя> --env API_KEY=значение --transport stdio -- <команда>

# Посмотреть / удалить:
claude mcp list
claude mcp remove <имя>
```

> `--` отделяет опции Claude от команды сервера: всё после `--` запускается
> как есть. Флаг `--scope project` кладёт сервер в `.mcp.json` в корне проекта —
> тогда он коммитится и доступен всей команде.

### Способ B — Claude Desktop (`claude_desktop_config.json`)

```json
{
  "mcpServers": {
    "weather": {
      "type": "stdio",
      "command": "python",
      "args": ["/абсолютный/путь/weather_server.py"],
      "env": {}
    }
  }
}
```

Для HTTP-сервера: `{ "type": "http", "url": "https://...", "headers": {} }`.

### Способ C — наше Android-приложение

Через слой `McpClient` из урока 02: на старте `listTools()` подмешивает каталог
инструментов в `systemPrompt`, а `callTool(...)` маршрутизирует вызовы на сервер.
Подключение сервера = строка конфигурации (команда+аргументы для stdio или URL
для HTTP), хранимая там же, где `selected_persona_id` (`ChatRepository`).

> Один и тот же сервер подключается всеми тремя способами без изменений — в этом
> и смысл стандарта (см. урок 02, раздел 6).

## 2. Каталог: какие MCP подключить к этому приложению

Каждый пункт: **что даёт → какой навык питает → транспорт → как подключить**.
Точные имена пакетов и URL со временем меняются — перед установкой сверяйтесь с
реестром MCP-серверов, синтаксис подключения остаётся прежним.

### 2.1. Погода → навык `weather_card`

- **Что даёт:** реальный прогноз вместо выдуманного моделью.
- **Питает навык:** `weather_card` (урок 01) получает настоящие `city`/`days`.
- **Транспорт:** stdio (наш пример `weather_server.py` из урока 02) или HTTP к публичному погодному MCP.
- **Подключение (Claude Code):**
  ```bash
  claude mcp add weather --env OPENWEATHER_KEY=xxxx --transport stdio -- python /path/weather_server.py
  ```

### 2.2. Задачи/заметки в файлах → навык `todo_list` / `table`

- **Что даёт:** чтение и запись задач и заметок в реальные файлы (официальный filesystem-сервер).
- **Питает навык:** `todo_list` (показать сохранённые задачи), `table` (список заметок).
- **Транспорт:** stdio.
- **Подключение (Claude Code):**
  ```bash
  claude mcp add notes --transport stdio -- npx -y @modelcontextprotocol/server-filesystem /home/user/notes
  ```
  > Передаём серверу разрешённую папку аргументом — он не выйдет за её пределы.

### 2.3. База данных (SQLite) → навыки `table` и `chart_bar`

- **Что даёт:** SQL-запросы к базе (например, к расходам или дневнику).
- **Питает навык:** `table` (строки результата) и `chart_bar` (агрегаты по месяцам).
- **Транспорт:** stdio.
- **Сценарий:** «покажи расходы за весну графиком» → инструмент делает `SELECT ... GROUP BY month` → модель кладёт результат в `chart_bar`.

### 2.4. Время и таймзоны → навыки `timer` / будущий `countdown`

- **Что даёт:** точное текущее время и часовые пояса (у LLM нет своих «часов»).
- **Питает навык:** `timer` и `countdown` — корректный отсчёт «сколько осталось до...».
- **Транспорт:** stdio.

### 2.5. Веб-выборка / поиск → обогащение любого ответа

- **Что даёт:** `fetch` страницы по URL или веб-поиск — свежие факты в чат.
- **Питает навык:** обычный текстовый ответ или `table` (сравнение вариантов).
- **Транспорт:** stdio (`fetch`) или HTTP (поисковый сервис).
- **Подключение (Claude Code):**
  ```bash
  claude mcp add fetch --transport stdio -- npx -y @modelcontextprotocol/server-fetch
  ```

### 2.6. Долгая память → персонализация ассистента

- **Что даёт:** memory-сервер (граф знаний) помнит факты о пользователе между сессиями.
- **Питает:** не карточку, а **поведение** — ассистент помнит ваши предпочтения, дополняя персону из урока 01.
- **Транспорт:** stdio.

### 2.7. Календарь / задачи внешнего сервиса → `todo_list`

- **Что даёт:** события и задачи из реального сервиса (через его HTTP-MCP).
- **Питает навык:** `todo_list` (ближайшие дела), `table` (расписание).
- **Транспорт:** HTTP, обычно с токеном:
  ```bash
  claude mcp add tasks --transport http https://example.com/mcp --header "Authorization: Bearer ТОКЕН"
  ```

## 3. Как выбрать, какой MCP вам нужен

Короткое правило для ревью идей:

1. **Нужны свежие/внешние данные?** (погода, веб, БД) → берите MCP-сервер.
2. **Нужно только красиво показать данные, которые уже есть?** → это локальный
   навык из урока 01, MCP не нужен.
3. **Данные приватные и на устройстве?** → stdio-сервер (локальный процесс).
   **Данные в облаке/общие?** → HTTP-сервер.
4. **Инструмент *делает* действие** (запись в файл, запрос) → это **tool**.
   **Просто подкладывает контекст** (содержимое файла) → это **resource** (урок 02, §8).

## 4. Безопасность подключения

MCP-сервер — это сторонний код и сторонние данные. Минимум:

- **Ставьте только доверенные серверы.** Сервер на stdio выполняется с вашими правами.
- **Ограничивайте область.** Filesystem-серверу давайте конкретную папку, БД — read-only пользователя.
- **Ключи — через `--env`/`headers`**, не в коде и не в коммитах.
- **Вывод сервера — непроверенный ввод.** Не подставляйте его напрямую в
  привилегированные действия и в текст с инструкциями для модели без проверки.
- **`--scope project` коммитит `.mcp.json`** — не кладите туда секреты, используйте
  подстановку переменных окружения (`${API_KEY}`).
