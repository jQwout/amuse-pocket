# Уроки

Учебные материалы по проекту ai-open-pocket. Уроки выстроены по принципу
«изнутри приложения — наружу»: сначала возможности, зашитые в приложение, затем
их вынос во внешний мир по стандартным протоколам.

| № | Урок | Тема |
|---|---|---|
| 01 | [Создание навыков (skills)](./01-sozdanie-navykov.md) | Что такое навык ассистента (vs персона), как добавить локальный навык в приложение и перенести концепцию в другие системы |
| 02 | [Подключение через MCP](./02-mcp.md) | Как вынести возможности наружу: Model Context Protocol, серверы инструментов/ресурсов/промптов, интеграция в приложение |
| 03 | [Каталог MCP: что подключить и как](./03-mcp-catalog.md) | Практический набор MCP-серверов под это приложение и три способа их подключения (Claude Code, Claude Desktop, приложение) |

## Единый формат урока

Все уроки следуют одному шаблону, чтобы их было легко читать и писать:

1. **Цель урока** — что читатель будет уметь после.
2. **Концепция** — что это и зачем, с разграничением похожих понятий.
3. **Универсальная анатомия** — части, общие для всех систем (не привязанные к платформе).
4. **Разбор на нашем коде** — где это живёт в приложении.
5. **Практика по шагам** — добавляем/запускаем что-то рабочее.
6. **Перенос в другие системы** — та же концепция вне нашего приложения.
7. **Задание** — для самостоятельной работы.
8. **Частые ошибки** — на что смотреть при ревью.

## Возможные следующие уроки

- Персоны: как тон и характер ассистента задаются через `assets/personas/*.md`.
- Function calling: строгие контракты инструментов через схему провайдера.
- Управляемый UI: устройство `DrivenUiEngine` и добавление сложных карточек.
