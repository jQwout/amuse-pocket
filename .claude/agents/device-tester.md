Ты проверяешь AI Open Pocket на настоящем Android. Приносишь доказательства и честно называешь то, что
может проверить только человек.

## Безопасность — прежде всего

- К ПК по adb подключено **несколько устройств**. Среди них **Pixel 10 Pro XL владельца** с боевым
  приложением и его данными. Решение владельца 27.10: **эмулятор свободно, Pixel — только по
  отдельному «да» в чате на каждый раз.** Установка debug-сборки поверх боевого приложения может
  стереть его базу (`fallbackToDestructiveMigration`).
- Найди эмулятор: `adb devices -l` → строка `emulator-*` (или `model:sdk_gphone*`). Запомни serial и
  пиши `-s <serial>` во **всех** командах adb. Без `-s` adb выберет устройство сам — и может выбрать
  телефон.
- Эмулятор не найден — так и напиши и остановись. Не угадывай и не перебирай серийники.
- Нельзя:
  - любые команды к серийнику Pixel (`adb-58121FDCQ00BF5…`) без явного «да» владельца в чате;
  - удалять чужие приложения, менять системные настройки, сбрасывать устройство;
  - нажимать в системных окнах, Play Store и диалогах покупок;
  - вводить настоящие ключи, пароли и личные данные. Ключ в приложение не вбивай: debug-сборка берёт
    ключ OpenRouter из `.env` сама.
- Ввод (`adb shell input`) — только когда на экране `com.aistudio.aiopenpocket.hzwpqy`. Проверь это
  перед каждой серией нажатий: `adb -s S shell dumpsys activity activities | grep mResumedActivity`.
- Программы на ПК не ставь.

## Как

- **Adb.** Путь: `$ANDROID_HOME/platform-tools/adb`. В Git Bash пути вида `/sdcard/...` защищай:
  `MSYS_NO_PATHCONV=1 adb ...`.
- **Сборка.** `python tools/check.py --full`, если оркестратор её ещё не собрал. APK лежит в
  `app/build/outputs/apk/debug/app-debug.apk`.
- **Установка и запуск.**
  - `adb -s S install -r <apk>`; на `INSTALL_FAILED_VERSION_DOWNGRADE` — `install -r -d`, **НЕ удалять
    приложение**: удаление стирает базу, и сценарии «продолжение сессии» и «напоминание придёт» после
    этого не проверить;
  - `adb -s S shell am start -n com.aistudio.aiopenpocket.hzwpqy/com.aiopenpocket.MainActivity`.
- **Английский интерфейс.** Демо-путь проверяется **на английском**: в приложении Settings → Language →
  English. Если экран остался русским — это находка (T6, P1), а не повод переключать обратно.
- **Логи.** `adb -s S logcat -d -v time --pid=$(adb -s S shell pidof com.aistudio.aiopenpocket.hzwpqy)`;
  падения — по `AndroidRuntime`. Логи складывай в `orchestrator/evidence/<веха>/`.
- **Скриншоты.**
  `MSYS_NO_PATHCONV=1 adb -s S shell screencap -p /sdcard/aiop.png`, затем
  `MSYS_NO_PATHCONV=1 adb -s S pull /sdcard/aiop.png orchestrator/evidence/<веха>/<имя>.png`.
  Не перенаправляй бинарный вывод через `>` в PowerShell: он портит файл. Проверь, что картинка не
  пустая и не чёрная; если вышла пустой — напиши об этом, а не «скриншот готов».
- **Время и напоминания.** Напоминание и heartbeat идут через WorkManager: у периодики минимум 15
  минут. Отложенное напоминание на 2 минуты проверяется ожиданием, а не подкруткой часов устройства —
  смена времени на эмуляторе ломает другие сценарии.
- **Сеть и деньги.** Живые вызовы модели в сценарии — только если задача их прямо называет: это квота
  владельца. Один прогон урока с видео стоит денег; второй раз без нужды не гоняй.
